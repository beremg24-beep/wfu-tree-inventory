Drone LiDAR Analysis & Campus Biodiversity Mapping

Project Overview

This project uses high-density drone LiDAR to create a digital inventory of trees across the Wake Forest University campus. By combining aerial LiDAR, ground classification algorithms, canopy height modeling, and tree segmentation techniques, we map individual trees and compute their height, crown dimensions, and spatial distribution.

Methods

The workflow includes LiDAR mission planning, point cloud preprocessing, CHM creation, watershed segmentation, GIS integration, and inventory generation. Data analysis was conducted using CloudCompare, LAStools, RStudio (lidR), and QGIS.

Results

The LiDAR dataset produced a detailed canopy height model (CHM) and allowed extraction of individual trees through segmentation. The results include tree height distributions, crown area metrics, and a high-resolution interactive tree map.
